# Portfolio Rebalancer

## Institutional Quant Platform

---

# Purpose

The Portfolio Rebalancer is responsible for maintaining alignment between the current portfolio and the target portfolio generated by the Portfolio Optimizer.

Rather than rebuilding the portfolio from scratch after every optimization cycle, the Rebalancer identifies portfolio drift, determines the minimum set of required trades, estimates transaction costs, and generates executable trade instructions while minimizing unnecessary turnover.

---

# Objectives

The Portfolio Rebalancer is designed to:

- Maintain portfolio alignment
- Detect portfolio drift
- Generate trade lists
- Minimize turnover
- Reduce transaction costs
- Preserve investment objectives
- Support multiple rebalancing strategies
- Produce execution-ready orders

# Portfolio Drift

Portfolio drift is measured as the difference between target and current allocations.

```text
Portfolio Drift

=

Target Weight

−

Current Weight
```

Example

| Security | Current | Target | Drift |
|----------|---------:|-------:|------:|
| ABC | 5.0% | 6.5% | +1.5% |
| XYZ | 8.0% | 6.0% | -2.0% |

# Rebalancing Methods

The platform supports multiple strategies.

---

## Periodic Rebalancing

Examples

- Daily
- Weekly
- Monthly
- Quarterly

Advantages

- Simple
- Predictable

Disadvantages

- May generate unnecessary trades

---

## Threshold-Based Rebalancing

Trades occur only when drift exceeds a threshold.

Example

```text
Drift

>

2%
```

Advantages

- Lower turnover
- Reduced costs

---

## Event-Driven Rebalancing

Triggered by:

- Earnings
- Corporate Actions
- Market Crashes
- Regime Changes
- Risk Breaches

---

## Risk-Based Rebalancing

Triggered when

- VaR exceeds limits
- Sector exposure exceeds limits
- Concentration increases
- Correlation changes significantly

---

## Hybrid Rebalancing

Combines

- Scheduled reviews
- Drift thresholds
- Event-driven triggers

# Turnover Management

Portfolio turnover is monitored.

```text
Turnover

=

Total Traded Value

/

Portfolio Value
```

High turnover may reduce net performance due to costs.

---

# Transaction Cost Awareness

Estimated costs include

- Brokerage
- Exchange Fees
- Securities Transaction Tax
- Stamp Duty
- Slippage
- Market Impact

The rebalancer may postpone low-impact trades when costs exceed expected benefits.
