# Dashboard Architecture

Version: 1.0

Status: APPROVED

---

# Purpose

This document defines the dashboard architecture of the
Institutional Quant Platform.

The dashboard provides visualization, monitoring, reporting,
and interaction with the platform.

The dashboard SHALL NEVER contain business logic.

---

# Objectives

The dashboard provides

• Portfolio visualization

• Risk dashboards

• Factor dashboards

• Performance dashboards

• Live monitoring

• Reports

• Administrative interfaces

# Responsibilities

Dashboard SHALL

• display information

• collect user input

• call REST APIs

• render charts

• display tables

• download reports

Dashboard SHALL NOT

• compute factors

• optimize portfolios

• calculate risk

• execute pipelines directly

• access storage directly
