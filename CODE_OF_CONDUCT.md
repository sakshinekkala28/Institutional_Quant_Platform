# Contributor Covenant Code of Conduct

## Our Pledge

We as members, contributors, and maintainers pledge to make participation in the Institutional Quant Platform community a harassment-free experience for everyone, regardless of:

- Age
- Body size
- Visible or invisible disability
- Ethnicity
- Sex characteristics
- Gender identity and expression
- Level of experience
- Education
- Socio-economic status
- Nationality
- Personal appearance
- Race
- Religion
- Sexual identity and orientation

We pledge to act and interact in ways that contribute to an open, welcoming, diverse, inclusive, and healthy community.

---

# Our Standards

Examples of behavior that contributes to a positive environment include:

- Being respectful and professional.
- Using welcoming and inclusive language.
- Accepting constructive feedback gracefully.
- Focusing on collaboration.
- Showing empathy toward other community members.
- Respecting different viewpoints and experiences.
- Helping new contributors learn the project.
- Prioritizing the security and stability of the platform.

Examples of unacceptable behavior include:

- Harassment or discrimination.
- Personal attacks or insults.
- Trolling or deliberately disruptive behavior.
- Publishing private information without permission.
- Threatening language.
- Sexualized language or imagery.
- Any behavior that would be considered inappropriate in a professional environment.
- Knowingly introducing malicious code or attempting to compromise the project.

---

# Enforcement Responsibilities

Project maintainers are responsible for:

- Clarifying and enforcing this Code of Conduct.
- Reviewing reports promptly and fairly.
- Taking appropriate corrective action.
- Protecting the privacy and security of reporters.

Maintainers may remove, edit, or reject contributions that violate this Code of Conduct.

---

# Scope

This Code of Conduct applies to:

- GitHub Issues
- Pull Requests
- Discussions
- Documentation
- Code Reviews
- Community communications
- Project-related events
- Any official project communication channels

It also applies when an individual is representing the project in public spaces.

# Enforcement Guidelines

Maintainers may take actions including:

## 1. Correction

A private warning explaining why the behavior was inappropriate.

---

## 2. Warning

A formal warning for repeated or more serious violations.

---

## 3. Temporary Restriction

Temporary suspension from participating in project activities.

---

## 4. Permanent Ban

Permanent removal from the community for severe or repeated violations.

---

# Enforcement Philosophy

Enforcement decisions will consider:

- Severity
- Intent
- Impact
- Previous behavior
- Willingness to improve

The goal is to maintain a safe, professional, and collaborative environment.
