# Security Issues

Do **NOT** report confidential security vulnerabilities through public GitHub Issues.

Please follow the responsible disclosure process described in:

```

SECURITY.md

```

---

# Reporting Guidelines

When opening an issue, please include:

- Platform version
- Operating system
- Python version
- Environment
- Logs
- Screenshots
- Steps to reproduce
- Expected behavior
- Actual behavior

Providing complete information helps resolve issues more quickly.
